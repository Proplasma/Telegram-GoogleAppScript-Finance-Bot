# Danh sách Ảnh Minh Họa Dự Án (Phiên bản 2.1.1)

Bạn có thể đặt các ảnh chụp màn hình vào thư mục `images/` này theo đúng tên bên dưới (hoặc sửa trực tiếp đường dẫn ảnh trên trình soạn thảo Web của GitHub tại các dòng `<!-- CHÈN ẢNH MINH HỌA ... -->` trong `README.md`):

1. `01-tong-quan-giao-dien-bot.png` : Ảnh chụp tổng quan menu `/help` và giao diện Bot trên Telegram.
2. `02-minh-hoa-ghi-giao-dich.png` : Ảnh chụp kết quả các lệnh `/c`, `/lcb`, `/clcb` kèm khung kẻ bảng.
3. `03-minh-hoa-gui-anh-bill-drive.png` : Ảnh chụp gửi kèm hóa đơn (Bill) và đường dẫn xem ảnh trên Google Drive.
4. `04-bao-cao-so-du-va-lich-su.png` : Ảnh chụp báo cáo số dư `/sodu` và lịch sử `/ls`.
5. `05-cau-truc-bang-google-sheets.png` : Ảnh chụp 5 trang tính trên Google Sheets (`Thu Chi`, `Quỹ Phụ`, `Hạn Mức`, `Lịch Sử Chốt Sổ`, `Logs`).
6. `06-kich-hoat-activatebot-gas.png` : Ảnh chụp màn hình điền `WEBAPP_URL` trong `F1ActivateBot.gs` và bấm Run `ActivateBot`.
7. `07-so-do-kien-truc-he-thong.png` : Ảnh sơ đồ luồng xử lý của hệ thống (tùy chọn).
