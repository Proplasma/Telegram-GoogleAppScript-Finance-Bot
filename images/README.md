# Danh sách Ảnh Minh Họa Dự Án (Phiên bản 2.2.0 - Hybrid UI)

Bạn có thể đặt các ảnh chụp màn hình vào thư mục `images/` này theo đúng tên bên dưới (hoặc sửa trực tiếp đường dẫn ảnh trên trình soạn thảo Web của GitHub tại các dòng `<!-- CHÈN ẢNH MINH HỌA ... -->` trong `README.md`):

1. `01-tong-quan-giao-dien-bot.png` : Ảnh chụp tổng quan menu `/help`, bàn phím đáy màn hình có nút `Open UI Mode` và luồng chọn nút 4 bước trên Telegram.
2. `02-giao-dien-open-ui-mode-3-tab.png` : Ảnh chụp màn hình đồ họa 3 Tab của `Open UI Mode` và bàn phím máy tính tích hợp (`+`, `-`, `×`, `÷`, `( )`).
3. `03-kich-hoat-activatebot-gas.png` : Ảnh chụp màn hình điền `WEBAPP_URL` trong `F1ActivateBot.gs` và bấm Run `ActivateBot` trên Google Apps Script.
4. `04-minh-hoa-ghi-giao-dich-va-bill.png` : Ảnh chụp kết quả ghi giao dịch `/c`, `/lcb`, `/clcb` và đường dẫn xem ảnh Bill trên Google Drive.
5. `05-bao-cao-so-du-va-lich-su.png` : Ảnh chụp báo cáo số dư `/sodu` và lịch sử `/ls`.
6. `06-cau-truc-bang-google-sheets.png` : Ảnh chụp 5 trang tính trên Google Sheets (`Thu Chi`, `Quỹ Phụ`, `Hạn Mức`, `Lịch Sử Chốt Sổ`, `Logs`).
7. `07-so-do-kien-truc-he-thong.png` : Ảnh sơ đồ luồng xử lý của hệ thống (tùy chọn).
